# AutoWise — мобільний застосунок

Expo SDK 58 + Expo Router. Екрани: підбір (розумний пошук і рейтинг), каталог, порівняння,
калькулятор витрат, кабінет (вхід, обране, збережені порівняння, гараж), сторінка авто,
аналіз оголошення.

```bash
npm install
npx expo start
```

Адреса API: змінна `EXPO_PUBLIC_API_URL`, а в режимі розробки — комп’ютер, на якому
запущено `expo start`, порт 8000. Токен входу зберігається в захищеному сховищі ОС
(`expo-secure-store`).

Збірка для магазинів: `npx eas-cli@latest build --platform android` (або `ios`).
