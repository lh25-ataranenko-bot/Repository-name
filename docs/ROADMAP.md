# План робіт AutoWise

Роботи переструктуровано з 5 етапів концепції у 3 потоки: **сервер і дані**, **сайт**,
**мобільний застосунок**. Сайт і застосунок не мають власної логіки розрахунків: усі
формули (TCO, оцінки, рейтинг, аналіз оголошення) живуть на сервері, тому результати
однакові на будь-якому пристрої.

## Стан на зараз

| Етап | Зміст | Сервер | Сайт | Застосунок |
|------|-------|:------:|:----:|:----------:|
| 1. MVP | Каталог (101 модифікація, 23 марки, роки 2007–2025), пошук, фільтри, картки авто, порівняння до 5 машин | ✅ | ✅ | ✅ |
| 2. Аналітика | Калькулятор TCO, рейтинги, графіки, ваги критеріїв | ✅ | ✅ | ✅ |
| 3. Дані | Імпорт CSV і Excel, редагування всіх полів, несправності, перевірка редактором, журнал змін, ролі | ✅ | ✅ адмінпанель | — (не потрібно) |
| 4a. Спільнота | Відгуки власників з модерацією, сторінки моделей, калькулятор розмитнення | ✅ | ✅ | ✅ |
| 4. Кабінет | Реєстрація, підтвердження пошти, відновлення й зміна пароля, обране, порівняння, гараж | ✅ | ✅ | ✅ |
| 5. Інтелектуальні функції | AI-помічник (Claude) з відповідями лише з каталогу, розумний пошук, аналіз оголошень | ✅ | ✅ | ✅ |

Каталог витримує 10 000 модифікацій: оцінки кешуються (запит 8–43 мс замість 1,2–1,6 с),
каталог віддається сторінками. Гараж у застосунку працює без мережі. Для сервера є
production-конфігурація з HTTPS, Redis і резервними копіями (`docs/DEPLOY.md`).

Застосунок має власну іконку й заставку (світла і темна тема) та профілі збірки EAS.
Сайт має карту сайту, robots.txt і структуровані дані schema.org. На GitHub налаштовано
автоматичні перевірки (CI).

## Що залишилося до публічного запуску

### Дані (найбільший обсяг)
- Домовитися з постачальниками ліцензованих даних (каталоги виробників, API характеристик,
  ринкові ціни, історія VIN) і замінити демо-каталог. Зараз усі 101 модифікація демонстраційні.
- Імпорт з API постачальників (зараз — CSV і Excel).
- Фото лише з дозволом використання (зараз — силуети за типом кузова).

### Сервер
- Підключити реальний SMTP-сервіс для листів і ключ Claude API для помічника.
- Набір перевірочних запитань (eval) для AI-помічника, щоб вимірювати якість відповідей.
- Понад ~100 000 модифікацій: перенести фільтрацію й сортування з пам’яті в SQL-запити.
- Історія цін і прогнози (потрібні ринкові дані за період).

### Сайт
- Купити домен і сервер, розгорнути за `docs/DEPLOY.md`, додати сайт у Google Search Console.

### Мобільний застосунок
- Обліковий запис розробника Google Play / Apple, перша збірка через EAS і публікація.
- Universal Links / App Links, щоб посилання з листів одразу відкривали застосунок
  (потрібен власний домен; зараз — кнопка на сторінці сайту зі схемою `autowise://`).

## Архітектура

```
Браузер ──► Next.js (web) ──/api/*──► FastAPI (backend) ──► PostgreSQL
Телефон ──► Expo (mobile) ──────────► FastAPI (backend)
```

Обробка запиту порівняння (як у концепції, розділ 9.1): клієнт надсилає ідентифікатори
модифікацій → API перевіряє запит і завантажує дані → нормалізує одиниці → модуль
порівняння будує таблицю й оцінки → сервер повертає структурований результат → інтерфейс
показує таблицю, графіки й пояснення.
