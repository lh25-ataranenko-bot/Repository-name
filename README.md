# AutoWise

Платформа для пошуку, порівняння й оцінювання конкретних модифікацій автомобілів:
каталог, порівняння до 5 машин, калькулятор вартості володіння (TCO), рейтинг за
вагами, аналіз оголошення перед купівлею, особистий кабінет із гаражем і адмінпанель.

Проєкт складається з трьох частин, які працюють з одним API і однією базою даних:

| Папка       | Що це                       | Технології                                   |
|-------------|-----------------------------|----------------------------------------------|
| `backend/`  | Сервер і API                | Python 3.13, FastAPI, SQLAlchemy, Alembic, PostgreSQL |
| `web/`      | Сайт                        | Next.js 16 (App Router), React 19, TypeScript |
| `mobile/`   | Мобільний застосунок        | Expo SDK 58, React Native, Expo Router       |
| `docs/`     | План робіт і архітектура    | —                                            |

> **Дані каталогу демонстраційні.** 47 модифікацій із правдоподібними характеристиками,
> цінами й типовими несправностями. Перед публічним запуском їх треба замінити
> ліцензованими даними (див. `docs/ROADMAP.md`, етап 3).

## Швидкий старт (Docker)

```bash
docker compose up --build
```

Сайт: http://localhost:3000 · API та документація: http://localhost:8000/docs

Адміністратор за замовчуванням: `admin@autowise.local` / `change-me-now`.
Для будь-якого реального розгортання задайте `AUTOWISE_JWT_SECRET` і `AUTOWISE_ADMIN_PASSWORD`.

### Пошта

Підтвердження пошти, відновлення пароля й сповіщення про зміну пароля надсилаються
листами. Задайте `AUTOWISE_SMTP_HOST`, `AUTOWISE_SMTP_USER`, `AUTOWISE_SMTP_PASSWORD`,
`AUTOWISE_SMTP_FROM` і `AUTOWISE_APP_URL` (адреса сайту для посилань). Поки SMTP не
налаштовано, листи лише записуються в журнал сервера, разом із посиланням.

### Адреса сайту

`SITE_URL` (для сайту) — публічна адреса, наприклад `https://autowise.ua`. З неї будуються
`/sitemap.xml`, `/robots.txt` і канонічні посилання сторінок авто (там же структуровані
дані schema.org для пошукових систем).

### Ролі

Нові користувачі мають роль «Користувач». Адміністратор призначає ролі в адмінпанелі:
редактор змінює, додає й перевіряє модифікації; адміністратор ще й видаляє їх і керує ролями.

## Запуск без Docker

Потрібні PostgreSQL 16, Python 3.13 і Node.js 22.

**Сервер:**

```bash
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env          # за потреби змініть адресу бази
alembic upgrade head          # створює таблиці
python -m app.seed.seed       # завантажує демо-каталог і адміністратора
uvicorn app.main:app --reload --port 8000
```

**Сайт:**

```bash
cd web
npm install
npm run dev                   # http://localhost:3000, /api/* проксіюється на :8000
```

**Мобільний застосунок:**

```bash
cd mobile
npm install
npx expo start                # відскануйте QR-код у Expo Go на телефоні
```

Профілі збірки — в `mobile/eas.json`. Перед першою збіркою замініть у ньому
`https://api.autowise.example` на адресу вашого сервера, потім:

```bash
npx eas-cli@latest build --platform android --profile preview   # APK для тестування
npx eas-cli@latest build --platform all --profile production    # для Google Play та App Store
```

Посилання з листа відновлення пароля можна відкрити в застосунку: на сторінці сайту
є кнопка «Відкрити в застосунку AutoWise» (адреса `autowise://account/reset?token=…`).

У режимі розробки застосунок сам звертається до API на комп’ютері, де запущено
`expo start` (телефон і комп’ютер мають бути в одній мережі Wi-Fi). Для збірки під
реальний сервер задайте `EXPO_PUBLIC_API_URL=https://api.ваш-домен`.

## Тести

Після кожного надсилання коду на GitHub тести й збірки запускаються автоматично
(`.github/workflows/ci.yml`): тести сервера з PostgreSQL і перевірка міграцій, перевірка
типів і збірка сайту, перевірка типів і збірка JavaScript застосунку.

```bash
cd backend && python -m pytest        # потрібна база autowise_test (див. tests/conftest.py)
cd web && npm run typecheck
cd mobile && npx tsc --noEmit
```

Тести перевіряють, зокрема, вимоги з концепції: більший пробіг збільшує витрати на пальне,
нижча ціна перепродажу збільшує TCO, бюджет працює як фільтр, а не як вага, відсутні
характеристики не підставляються з інших модифікацій.

## Основні адреси API

| Метод | Шлях                         | Призначення |
|-------|------------------------------|-------------|
| GET   | `/api/cars`                  | Каталог із фільтрами й сортуванням |
| GET   | `/api/cars/{slug}`           | Модифікація з оцінками й несправностями |
| GET   | `/api/catalog/tree`          | Ієрархія марка → модель → покоління → модифікація |
| POST  | `/api/compare`               | Таблиця порівняння 2–5 авто з підсумком |
| POST  | `/api/tco`                   | Вартість володіння з вашими припущеннями |
| POST  | `/api/rating`                | Зважений рейтинг з обов’язковими фільтрами |
| POST  | `/api/search/parse`          | Запит звичайною мовою → фільтри |
| POST  | `/api/check`                 | Аналіз оголошення: ціна, VIN, чекліст |
| POST  | `/api/auth/register`, `/login` | Реєстрація і вхід (JWT); 5 невдалих спроб за 15 хв блокують вхід |
| POST  | `/api/auth/verify`, `/resend-verification` | Підтвердження пошти |
| POST  | `/api/auth/forgot`, `/reset` | Відновлення пароля через лист |
| *     | `/api/me/...`                | Профіль, зміна пароля, обране, збережені порівняння, гараж |
| *     | `/api/admin/...`             | Якість даних, імпорт CSV і Excel (.xlsx), створення, редагування, перевірка й видалення модифікацій, несправності, журнал змін, ролі |

Повний опис — у Swagger: http://localhost:8000/docs
